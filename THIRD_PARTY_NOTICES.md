## Frontend
Веб-интерфейс (`static/index.html`) написан на чистом HTML/CSS/JavaScript **без сторонних библиотек, шрифтов и CDN**. Используются системные шрифты.

## Документация API
Страницы `/docs` (Swagger UI) и `/redoc` (ReDoc), генерируемые FastAPI, загружают скрипты с CDN jsdelivr. Swagger UI — Apache-2.0, ReDoc — MIT. Для работы этих страниц нужен интернет; для работы самого продукта — не нужен.

## Модели, датасеты, ИИ
**Не используются.** Скоринг — формализованная балльная модель с правилами, заданными вручную (`docs/ASSUMPTIONS.md`). LLM, предобученные модели и внешние датасеты в проекте отсутствуют.

## Данные
Все данные (компании, ИНН, руководители, финансовые показатели, кредитные истории, пользователи) — **синтетические**, созданы автором для демонстрации. Совпадения с реальными лицами случайны. ИНН вида `77012345xx` вымышлены.
